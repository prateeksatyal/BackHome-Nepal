# 🏠 BackHome Nepal

## Premium AI-Powered Mobile Application for NRNs & Returnees

A survival assistant + comfort companion app helping people returning from abroad (especially UK) adapt emotionally, physically, and socially to life in Nepal.

### 🎯 Mission
Reduce reverse culture shock, stress, loneliness, and confusion while helping users feel comfortable and happy in Nepal again.

---

## ✨ Core Features

### 🏙️ **1. Comfort Zone Finder**
- AI-powered map with clean cafes, premium gyms, quiet workspaces
- Ratings: "Feels like London", Air quality, Noise level, Foreigner friendliness, Hygiene, WiFi speed

### 🤖 **2. AI Nepal Survival Assistant**
- Instant answers: "Is this area safe?", "How much taxi?", "Can I drink this water?"
- Calm, supportive, locally expert tone

### 🌫️ **3. Pollution & Health Protection**
- Real-time AQI, dust, UV alerts
- Smart adaptation tips: "Wear mask", "Avoid outdoor gym"
- Low pollution café recommendations

### 🧘 **4. Reverse Culture Shock Support** ⭐ MAIN FEATURE
- Daily emotional check-ins
- Homesickness tracker & mood journal
- Therapy-style AI conversations
- Anonymous community vent section
- "People like me nearby" feature

### 🚕 **5. Smart Safe Transport**
- Safest taxi apps integration
- Price estimator & scam warnings
- Dangerous area alerts
- Women safety mode
- Live location sharing

### 🍽️ **6. Safe Food & Water Guide**
- AI restaurant recommendations
- Stomach safety ratings, cleanliness scores
- Safe street food guide
- Filtered water stations locator

### 💬 **7. Nepali Social Translator**
- Understand slang, sarcasm, local behavior
- Cultural customs guide
- Hidden meanings decoder

### 👥 **8. Community & Friends**
- Connect UK returnees, NRNs, tourists, expats
- Meetup events, gym buddies, café hangouts
- "New in Kathmandu" groups

---

## 💎 Premium Features

- **Homesick Mode**: UK radio, BBC news, London sounds, tea reminders
- **Comfort Score**: Daily recommendations based on stress, pollution, social activity
- **First 30 Days Guide**: Structured adaptation plan

## 📱 Tech Stack

- **Frontend**: Flutter (cross-platform iOS/Android)
- **Backend**: Node.js + Express
- **Database**: Firebase Firestore
- **Auth**: Firebase Authentication
- **AI**: OpenAI API (GPT-4)
- **APIs**: Google Maps, AQI API, Weather API, Translation API
- **Real-time**: Firebase Realtime Database
- **Design**: Glassmorphism, premium animations

## 🚀 Quick Start

### Prerequisites
- Flutter SDK 3.0+
- Node.js 18+
- Firebase CLI
- OpenAI API Key

### Setup

```bash
# Clone repository
git clone https://github.com/prateeksatyal/BackHome-Nepal.git
cd BackHome-Nepal

# Mobile Setup
cd mobile
flutter pub get
flutter run

# Backend Setup
cd ../backend
npm install
npm run dev
```
